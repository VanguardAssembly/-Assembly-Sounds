// Which source texts each session comes from (read by src/texts.rs).
//
//   session-id other-id prefix*: text_id | text_id = note on how this session uses it
//
// Every line that matches a session adds its texts, in file order; a text is listed once.
// `prefix*` matches every session id that starts with the prefix.
//
// The texts live in the other .txt files in this folder. Each entry looks like this:
//
//   @ text_id
//   title: English title
//   orig: original title, language or script
//   by: author or attribution
//   date: when
//   fam: library group (see FAMS in texts.rs)
//   kind: scripture | sutra | treatise | manual | poem | prayer | teaching | liturgy | ritual | book | study | review | report | history
//   cite: full reference (studies and books)
//   credit: who translated the passages
//   more: further reading (one per line, repeatable)
//   full: yes          (only when the passages are the complete text)
//   about:
//   What the text is and how the practice comes from it. Blank lines start new paragraphs.
//   ## Passage heading
//   The passage in English.  "> " lines are verse, "- " bullets, "1. " numbered,
//   "= " original-language lines. *italic* and **bold** work everywhere.
//
// Translations are our own plain-English renderings unless a public-domain translation is
// credited. Modern works still under copyright are summarised in our own words, never quoted.
